Katalog zawiera program ćwiczenie 2, który uruchamia inny program za pomocą funkcji execlp, który wypisuje komunikaty procesów potomnych.
Progam uruchamiany przez funkcję execlp wypisuję UID, GID, PID, PPIG i PGID procesów potomnych.
Z linii koment należy również podać program do uruchomienia.
Przykład:
./cw2 ./ID
